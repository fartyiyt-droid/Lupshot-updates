# Lupshot — обновления Windows
Публичный канал обновлений Lupshot. Исходный код хранится отдельно в приватном репозитории. Здесь размещаются только готовые установщики и файл текущей версии.
## Как работает обновление
Lupshot 0.4.0 проверяет `latest.txt` при запуске и каждые шесть часов. Если опубликована более новая версия, программа запрашивает подтверждение, загружает установщик по HTTPS и проверяет его SHA-256. Только после успешной проверки запускается установка.
**Важно:** до первой опубликованной версии `latest.txt` намеренно отсутствует, поэтому приложение продолжает работать без уведомлений о несуществующих обновлениях.
## Выпуск обновления
1. Соберите и проверьте Lupshot в приватном репозитории.
2. Опубликуйте `Lupshot-Setup.exe` как файл релиза в этом публичном репозитории.
3. Рассчитайте SHA-256 установщика.
4. Создайте `latest.txt` в корне ветки `main` из трёх строк: версия (например `0.4.1`), полный HTTPS URL установщика, SHA-256 в виде 64 шестнадцатеричных символов.
5. Только после успешной публикации установщика обновляйте `latest.txt`; иначе пользователям придёт уведомление о нерабочем обновлении.
## Защита
Не публикуйте исходные файлы, ключи API, пароли, токены GitHub или приватные архивы. Для критически важных сценариев стоит добавить цифровую подпись установщика и подписанный манифест: SHA-256 сам по себе не защищает от подмены одновременно установщика и манифеста.
